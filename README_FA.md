# دفتر کلاسی اختصاصی — نسخه PWA با دکمه نصب

این نسخه دارای دکمه «📲 نصب برنامه» است.

وقتی برنامه از یک آدرس HTTPS معتبر (مثل GitHub Pages یا Netlify) باز شود، در مرورگرهای پشتیبان:
- دکمه «نصب برنامه» نمایش داده می‌شود.
- کاربر می‌تواند برنامه را روی گوشی نصب کند.
- آیکن برنامه روی صفحه اصلی قرار می‌گیرد.
- برنامه به‌صورت مستقل و تمام‌صفحه اجرا می‌شود.

اگر مرورگر دکمه نصب را به‌صورت خودکار ارائه نکند، برنامه راهنمای استفاده از منوی Chrome را نمایش می‌دهد.

نکته مهم:
باز کردن فایل HTML از داخل حافظه گوشی (`file://`) معمولاً نصب PWA را فعال نمی‌کند. برای نصب واقعی باید برنامه از HTTPS اجرا شود.
